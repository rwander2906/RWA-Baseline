# Bootstrap Tool

The bootstrap tool creates a new project skeleton based on the current RWA Baseline.

## Requirements

- Python 3.11+
- no Python dependencies
- optional: GitHub CLI `gh` for supported repository settings

## Dry run

```bash
python scripts/bootstrap_project.py ../my-project --profile python --dry-run
```

or:

```bash
python scripts/bootstrap_project.py ../my-node-project --profile node --dry-run
```

## Create project

```bash
python scripts/bootstrap_project.py ../my-project --profile python --name "My Project"
```

The tool creates baseline metadata, README/Changelog, architecture/project-guideline placeholders, GitHub issue/PR templates, promotion gate and a profile-specific CI skeleton.

Existing target files are never silently overwritten. If any generated path already exists, bootstrap aborts and reports all conflicts.

## Optional GitHub settings

If `gh` is installed and authenticated:

```bash
python scripts/bootstrap_project.py ../my-project \
  --profile python \
  --github-repo owner/my-project \
  --configure-github
```

Currently supported:
- delete branch on merge
- enable auto-merge capability

Branch protection/rulesets remain a follow-up because they depend on repository/plan capabilities and should be generated by the compliance/bootstrap evolution rather than guessed.

## After bootstrap

Continue with [New Project Checklist](../checklists/NEW_PROJECT.md). In particular, create `staging`, configure branch/ruleset protection, and verify CI before feature work starts.
